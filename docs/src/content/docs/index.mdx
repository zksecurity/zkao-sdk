zkao audits code for security bugs, with a focus on cryptography and zero-knowledge circuits.
Everything you can do on a project in the app, you can also do through its API.

```bash
npm install -g @zksecurity/zkao-cli
zkao login
zkao scans launch --repo <repoId> --budget 500
```
